Kasir Sahabat Jaya Motor

Aplikasi kasir dan stok untuk toko sparepart motor.

Buka Aplikasi Kasir

Pasang di layar HP Android (Chrome)

  1. Buka aplikasi lewat tombol di atas.
  2. Tekan titik tiga di pojok kanan atas Chrome.
  3. Pilih Tambahkan ke layar utama atau Instal aplikasi.
  4. Tekan Tambahkan. Ikonnya muncul di layar HP.

Pasang di iPhone (Safari)

  1. Buka aplikasi lewat tombol di atas, memakai Safari.
  2. Tekan tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambah ke Layar Utama, lalu tekan Tambah.

Sebelum mulai berjualan

  1. Buka menu Pengaturan, lalu isi nama toko, alamat, dan nomor telepon.
  2. Tekan Buat PIN pemilik supaya aplikasi terkunci.
  3. Tambahkan produk di menu Produk, lalu catat stok di menu Stok.
  4. Unduh cadangan data di menu Pengaturan secara rutin.

Data tersimpan di browser HP ini saja. Jangan hapus data browser sebelum mengunduh cadangan.
